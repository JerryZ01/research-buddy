# 编辑型文章生成管线

## 目标

把文章质量的主要控制点从「持续堆叠写作 Prompt」前移到证据、判断和编辑任务。管线必须满足：

- 具体断言能追溯到真实搜索证据。
- 写作前先确定文章的唯一核心判断、范围和章节职责。
- 审校输出是可执行的局部修改，不是再次整篇重写。
- 任何新节点失败时可降级，不阻断现有出稿能力。

## 目标流程

```text
问题拆解 -> 搜索 -> 证据充分性验证
                         |
                         v
              证据账本 + 编辑简报
                         |
                         v
                      文章初稿
                         |
                         v
          事实审校 -> 论证审校 -> 语言审校
                         |
                         v
                    局部修改后定稿
```

## 分阶段实施

### 阶段 1：证据账本与编辑简报（已接入）

`editorial_planner` 位于 `validator` 和 `synthesizer` 之间。

证据账本由确定性代码构建：

- 以规范化 URL 去重，不另外调用模型。
- 保留原始证据摘录，不让 LLM 预先改写证据。
- 合并关联子问题、证据验证状态和已知冲突。
- 使用 `E1`、`E2` 等稳定编号，编辑简报和写作输入共用同一映射。

编辑简报产出：文章意图、目标读者、核心判断、包含/排除范围、必讲要点、章节职责、证据映射、禁止断言和收束方式。代码会删除幻觉证据编号；简报结构不完整时整体丢弃，降级到原有写作流程。

这一阶段每次进入初稿前新增一次非流式 LLM 调用。反思只要求用当前证据改写时复用已有简报；只有追加搜索经过验证后才重建账本和简报。

### 阶段 2：事实审校（待接入）

对初稿中的数字、工具行为、因果关系和具体建议做断言级检查。审校器只能返回「原文精确片段 + 替换文本 + 支持证据原句」。代码验证原文和证据原句都真实存在后才应用。

接入前必须先解决：

- 编辑后的文章如何通过 SSE 替换已经流式展示的初稿。
- 审校轮数和独立证据复核如何设置调用预算。
- 如何避免局部删除制造悬空连词、标点或上下文断裂。

### 阶段 3：论证审校（待实现）

检查每节是否完成编辑简报中的职责，是否存在结论跳跃、重复论证、忽略冲突证据或“证据与结论之间缺一步”。该节点不负责事实补全，只调整论证或明确降低结论强度。

### 阶段 4：语言审校（待实现）

最后处理不增加信息的模板句、假想对立、仪式化总结、连续反问和过度对称的章节结构。语言审校在事实和论证审校之后执行，不得为了“更像人”添加新事实。

## 暂不做的事

- 不把反思轮数继续当作主要质量手段。
- 不让一个综合评审 Prompt 同时承担事实、论证和文风审校。
- 不在没有证据支持时使用模型训练知识补全搜索结果。
- 不在本阶段启动文章质量回归任务。
