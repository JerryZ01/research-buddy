Research Buddy · 系统架构

输入一个问题，自动拆解、搜索、验证，生成带来源引用、配图与质量评审的编辑型文章

接入层
Web UI
研究与进度实时呈现，SSE 流式接收进度、正文与配图
HTTP / SSE 客户端
35 个端点，支持同步、流式与人机交互中断恢复
REST / Server-Sent Events
接口层
FastAPI 应用
研究 / 主题 / 追踪 / 素材库四组路由，统一错误处理与静态图片服务
LangGraph 编排
4 种工作流：标准 / 人机交互 / 增量 / 定时追踪
调度 15 个节点
核心层 · 文章生成链路
① 研究与证据
planner 拆解子问题
searcher 并行搜索与全文抓取
validator 覆盖度与语义双闸
local_lookup 本地代码检索
② 编辑型写作
editorial_planner 定角度章节
synthesizer 流式长文写作
language_editor 改写模板句
article_editor 局部事实校验
③ 混合配图
image_planner 判定 need 推导图源
image_reviewer 图文匹配复核
搜图优先，搜不到宁可不配
生图限示意图，标注不冒充事实
④ 质量控制
reflector 三维度评估
独立 Judge 打分与硬规则校验
最佳稿保留，不合格不交付
不达标自动补搜或重写
沉淀与复用
支撑层
知识与追踪

diff_analyzer 变化检测 · change_notifier 多平台通知
文章素材库
