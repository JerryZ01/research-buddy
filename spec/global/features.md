# 已有功能清单

![功能模块概览](./images/05-feature-modules.png)

## 研究核心
- **智能拆解:** LLM 将研究问题按复杂度拆解为 1-6 个必要子问题，并生成多语言搜索词。
- **并行搜索:** 最多 4 线程并行调用 Tavily，按规范化 URL + 内容 SHA-256 双重去重。
- **证据验证:** 确定性硬闸（每子问题 ≥2 条结果、≥2 个域名、覆盖度 ≥0.75）+ LLM 语义软闸（≥0.6）。
- **报告综合:** LLM 流式生成结构化报告，带来源引用、置信度评估，正文可直接发布。
- **自我反思:** 独立模型从完整性/准确性/清晰度三维打分，不达标自动补搜或重写，恢复最佳历史稿。
- **自动续写:** 检测正文被提供商截断时自动续写并去除重叠片段，最多 2 次。

## 编辑审校
- **编辑简报:** 写作前生成证据账本与编辑简报（意图、读者、必讲要点、证据映射、禁止断言）。
- **语言审校:** 确定性扫描高置信模板表达，模型仅做局部替换（最多 8 处），保证数字/引用/URL 不变。
- **事实审校:** 对数字、因果关系、具体建议做证据定向审校，需原文精确片段 + 证据支持 + 独立 grounding 复核。
- **图片管线:** 候选图片经下载校验 → 视觉模型筛选（先抄写叠加内容再判定水印）→ 入选图逐张独立复核 → 内容哈希缓存 → 占位符插入。
- **图片水印过滤:** 两道检查均 fail-closed，拒绝水印、署名叠字、账号 ID、二维码、版权叠印等不可用图片。

## 知识与追踪
- **知识召回:** 从 SQLite + ChromaDB 召回历史报告、关键事实与相关分块，支持增量研究。
- **增量研究:** 只规划缺失信息，用历史来源 URL 去重，`parent_report_id` 串成版本链。
- **知识入库:** 最终报告写入 SQLite，报告分块与关键事实写入 ChromaDB。
- **定时追踪:** APScheduler 按 cron 对主题执行追踪研究。
- **变化通知:** 文本相似度预判 + LLM 结构化变化提取，高等级/多中等级变化触发 Webhook 通知。

## 素材库与评估
- **文章素材库:** 每次生成、阶段版本、评价和策展状态永久留痕（`article_generations` / `article_versions` / `article_reviews`）。
- **版本比较:** 前端对两个 `article_versions` 做差异高亮。
- **LLM-as-Judge:** Langfuse 数据集 + 独立 Judge 自动评分。
- **文章质量回归:** 冻结搜索证据，对 baseline/candidate 多次采样，生成 JSON/HTML 对比报告。
- **Prompt 管理:** Langfuse 远程 Prompt（`production` 标签）+ 本地 fallback，启动不自动覆盖发布版本。

## 交互与界面
- **Web UI:** 深色主题 SPA，SSE 流式展示、Markdown 渲染、目录、复制与导出。
- **SSE 流式输出:** `start`/`node_start`/`message`/`report_chunk`/`report`/`done` 等事件实时推送。
- **人机交互（HITL）:** 搜索前确认子问题、反思前审阅文章，支持断线恢复。
- **断线恢复:** SSE 后台线程运行，`runs` 表保存状态，`/research/run/{run_id}` 轮询恢复结果。
- **问题优化:** 研究前通过 `/research/refine-question` 整理问题。
